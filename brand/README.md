# Nexvance brand assets
Rebuilt as vector from `nexvance-official-color-options.pdf` (Option A palette on light, Option C on dark). Text is outlines (DejaVu Sans), so no font is needed. Replace with the designer's original vector when available.

| File | Use |
|---|---|
| `nexvance-logo-light-bg` | Full logo on white/light backgrounds |
| `nexvance-logo-dark-bg` | Full logo on dark/blue backgrounds |
| `nexvance-logo-mono-black` / `-white` | One-colour print, stamps, watermarks |
| `nexvance-mark-*` | Icon only (hexagon NV). Use below 32 px tall, favicons, avatars |
| `nexvance-app-icon` | Rounded white tile for app icons |

Accessible colours (WCAG on #fbfbfd): ink #1a1a2e 16:1, indigo #5b4bf0 5.5:1, SOLUTIONS #6b6885 5.2:1, outline #8a7dff 3.1:1.
Dark (#1c203e): white 15.8:1, #8c9bff 6.2:1, SOLUTIONS #8a8eb0 5:1, outline #7480dc 4.4:1.
The original PDF's lighter indigo (#6c5cff) and grey (#a09db5) failed contrast for text, so they were darkened.
Rules: minimum 32 px tall for the full logo (use the mark below that); keep clear space equal to the hexagon's width on every side; do not recolour, stretch or add effects.
The app serves copies from `frontend/public/brand/`; `frontend/public/favicon.svg` is the light mark.
